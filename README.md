# MERN Login App

This is a simple Login Application built using the MERN stack.

## Tech Stack
- Frontend: React.js
- Backend: Node.js + Express.js
- HTTP Client: Axios
- Routing: React Router

## Features
- User login form
- API integration between React frontend and Node backend
- Displays error message for invalid credentials
- Redirects to welcome page on successful login
- Uses React functional components and Hooks

## Project Structure
login-app

├── backend
│   └── server.js
│
├── frontend

│       ├── App.js
│       ├── Login.js
│       └── Welcome.js

## Running the Project

### Backend

cd backend
npm install
node server.js


Server runs on **http://localhost:5000**

### Frontend

cd frontend
npm install
npm start


Frontend runs on **http://localhost:3000**
